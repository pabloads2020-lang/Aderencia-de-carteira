Metodologia · Aderência de Carteira
Como o percentual de aderência de cada cliente é calculado.

1. O que é a Aderência

A Aderência mede o quanto a carteira efetiva de um cliente se sobrepõe à carteira recomendada para o perfil dele (Conservador, Moderado, Agressivo), considerando a distribuição percentual por classe de ativo.

2. Fórmula — soma dos mínimos por classe

Para cada classe de ativo, compara-se o percentual que o cliente efetivamente possui naquela classe (posição na classe / patrimônio total classificado) com o percentual que a carteira recomendada do perfil indica para essa mesma classe. O menor dos dois valores é somado ao indicador final:

Aderência = soma, para cada classe, de mín( % atual na classe , % alvo na classe )

O resultado varia de 0% a 100%: quanto mais a distribuição do cliente "encaixa" dentro do que é recomendado, mais próximo de 100% fica o indicador. Alocações fora do perfil — a mais ou em classes não recomendadas — não somam pontos, pois o mínimo entre atual e alvo penaliza tanto excesso quanto falta.

3. Corte de aderência

Considera-se o cliente ADERENTE quando Aderência ≥ 80%. Esse corte é o usado em todos os filtros e exportações do sistema.

4. Carteiras recomendadas por perfil

Percentuais de referência vigentes no momento. Podem ser ajustados na tela "Editar %" (área protegida por senha), passando a valer imediatamente no cálculo.

5. Origem dos dados de posição

Cadastro de Clientes: define código, nome e perfil — determina qual carteira recomendada usar no cálculo.

Posições dos Clientes: base em massa com o patrimônio de cada cliente já classificado por classe de ativo.

XPerformance (PDF): relatório individual; as posições são extraídas do PDF e classificadas nas mesmas classes do sistema. Caixa e Proventos são tratados como liquidez Pós-fixado, para não penalizar a aderência por saldo em trânsito. Ambas as fontes alimentam o mesmo cálculo, sem distinção.

6. % do CDI (indicador complementar)

Calculado a partir da Base de Rentabilidade mensal do cliente:

Rentabilidade acumulada = (1 + r1) × (1 + r2) × ... × (1 + rn) − 1
CDI acumulado = (1 + cdi1) × (1 + cdi2) × ... × (1 + cdin) − 1
% do CDI = (Rentabilidade acumulada / CDI acumulado) × 100

Pode ser calculado sobre todo o histórico disponível ou restrito a um período (ano) selecionado nos filtros avançados, e é usado em conjunto com a Aderência no filtro combinado "Aderência × CDI".

7. Limitações

O cálculo depende da classificação correta de cada ativo nas classes padronizadas do sistema; erros de classificação na origem (base ou PDF) afetam o resultado. Sem posição classificada (patrimônio total = 0) ou sem perfil cadastrado, a Aderência não é calculada para o cliente. O % do CDI só é calculado quando há registros de CDI no mesmo período da rentabilidade do cliente.
